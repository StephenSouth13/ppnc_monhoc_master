## Overview | Tổng quan

This repository stores materials, article analysis, and assignments for the **Research Methodology** course at UEH.  
The focus is on **scientific research design, literature review, and quantitative methods** used in economics and finance.

Repository này lưu trữ tài liệu, bài phân tích và bài tập của môn **Phương pháp nghiên cứu khoa học** tại UEH, tập trung vào **thiết kế nghiên cứu, lược khảo tài liệu và phương pháp định lượng**.
